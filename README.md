# 予你星河 · Cinematic surprise gift

Open **[/cinema/](https://tidy-data.github.io/gift-demo/cinema/)** for the current one-minute full-screen interactive prototype.

- Pre-rendered original AI shots, no player controls or borders.
- Portrait phone and landscape desktop masters; no black bars.
- Tap-to-open, screen shake, canvas particles, original procedural score, optional Android haptics.
- No recipient/sender fields, no name parameters, no tracking.
- Three generic preset blessings (birthday default); optional `msg` is length-limited and stripped of control characters.
- `?timeout=5` is the retained expiry testing parameter.

The earlier WebGL demo has been disabled because it rendered personalised names. Its executable JavaScript has been removed.

This is a visual prototype, not a payment or gift-delivery product. Sound starts after the opening tap. Actual phone playback depends on browser codec support and network conditions.
